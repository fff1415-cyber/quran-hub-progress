# خطة التطوير الشاملة

## 1) جعل البيانات دائمة عبر Lovable Cloud (بدلاً من localStorage فقط)

**المشكلة الحالية:** البيانات محفوظة في `localStorage` فقط، لذا تختفي عند فتح الموقع من جهاز آخر.

**الحل:** إنشاء جداول في قاعدة بيانات Cloud:
- `students` — جميع بيانات الطلاب (مع `assigned_to`: teacher/assistant/null)
- `halaqat` — الحلقات والمعلمين
- `role_accounts` — حسابات الإداريين/المشرفين/المدير/السكرتير/المسمّعين (مع `code` و`permissions`)
- `grades` — جدول الحفظ الأسبوعي
- `sard_queue` و`sard_history` — طابور السرد والتاريخ
- `attendance_daily` — سجل غياب اليوم (يُستخدم في التحديث اليومي 2 ظهراً)

**سياسات الوصول (RLS):** قراءة عامة (لأن الدخول بالرموز لا بالحساب)، والكتابة عبر Server Functions تتحقق من رمز المستخدم.

**استيراد Google Sheets** → يكتب مباشرة في جدول `students` (يُحدّث الموجود حسب `national_id`، ويضيف الجديد). فالطلاب يصبحون **دائمين على كل الأجهزة** ولا يُحذفون إلا من زر «حذف الطالب» في صفحة الإداري.

## 2) صفحة المعلم/المساعد — منطق التعيين

- الأصل: **كل طلاب الحلقة يظهرون عند المعلم وعند المساعد**.
- عند تعيين طالب لأحدهما (`assignedTo = "teacher" | "assistant"`)، يظهر فقط عند الجهة المُعيَّن لها ويختفي عن الأخرى.
- زر «إلغاء التعيين» يعيده للجميع.

## 3) صفحة المسمّع (السرد)

- إضافة قسم **«قائمة الانتظار»** يعرض أسماء الطلاب المُحالين (`status: pending | scheduled | approved_third`) مع: اسم الطالب، الحلقة، الأسبوع، رقم المحاولة، وقت الجدولة.
- زر «بدء التقييم» بجانب كل اسم.
- يبقى احتساب الدرجات كما هو (45 حفظ + 50 مراجعة، نجاح ≥80%).

## 4) صلاحية «إعادة المستوى خلال أقل من يومين»

- في **صفحة المشرف التعليمي** و**صفحة الإداري**: زر «السماح بإعادة السرد فوراً» على أي طالب في حالة `scheduled` → يضبط `scheduledAt = now()` ويصبح `pending` مباشرة.

## 5) جدول الحفظ — إخفاء الدرجة

- في `teacher.tsx`: عمود الحفظ يعرض **الكمية فقط** (½ / ١ / ٢) بدون قيمة الدرجة (15/20/25).
- الدرجة تبقى محسوبة داخلياً للنسبة المئوية، لكنها لا تُعرض في الخلية.

## 6) صفحة الطالب/ولي الأمر — إعادة هيكلة

عند فتح الصفحة بدون تسجيل دخول، تظهر فقط:
1. **تقدم الحلقات** (رسوم بيانية دائرية لكل حلقة).
2. **لوحة الشرف** — أفضل 15 طالباً.
3. حقل إدخال **رقم الهوية**.

بعد إدخال رقم الهوية الصحيح، تظهر **بيانات الطالب فقط** (وليس قائمة كل الطلاب):
- عدد المقاطع المحفوظة.
- عدد مرات الغياب وعدد مرات التأخر.
- **حالة اليوم**: حاضر / غائب / متأخر / مستأذن.
- النسبة العامة للطالب.

(يُحذف محرك البحث الحالي الذي يُظهر كل الطلاب.)

## 7) غياب اليوم في صفحتي السكرتير والإداري

- قسم «غياب اليوم» يعرض جدولاً: اسم الطالب، الحلقة، الحالة (غائب/متأخر/مستأذن)، **زر واتساب** بنقرة واحدة لولي الأمر.
- **التحديث اليومي:** يتم تحديد «اليوم» بناءً على وقت الحفظ، ويتجدد العرض **كل يوم الساعة 2 ظهراً**. يُنفَّذ ذلك بحساب «تاريخ اليوم الفعلي» = `today` إذا كانت الساعة ≥ 14:00، وإلا = `yesterday` (منطق `getOperationalDate()` في الواجهة، لا يحتاج Cron).
- صفحة السكرتير جديدة (`/secretary.tsx`) مشابهة للإداري لكن للقراءة فقط + واتساب.

## 8) إدارة الصلاحيات من لوحة المدير فقط

- جدول `role_accounts` يحوي عمود `permissions` (مصفوفة نصية).
- صفحة جديدة داخل `/manager.tsx`: **«المستخدمون والصلاحيات»**
  - عرض كل المستخدمين (المدير، السكرتير، المشرف، المعلمون، المساعدون، المسمّعون).
  - إضافة مستخدم (اسم + دور + رمز عضوية + صلاحيات).
  - تعديل الصلاحيات لكل مستخدم (Checkboxes: `manage_students`, `manage_halaqat`, `approve_sard`, `view_attendance`, `import_sheets`, `edit_grades`, إلخ).
  - حذف مستخدم.
- التحقق من الصلاحية يتم في كل صفحة حسّاسة عبر دالة `hasPermission(user, perm)`.

## التفاصيل التقنية

**ملفات جديدة:**
- `src/routes/secretary.tsx`
- `src/lib/permissions.ts` — تعريف الصلاحيات ودالة `hasPermission`
- `src/lib/cloud-store.ts` — طبقة وصول لـ Supabase تستبدل `mock-data.ts` تدريجياً
- `src/lib/operational-date.ts` — منطق «اليوم 2 ظهراً»

**ملفات تُعدَّل:**
- `mock-data.ts` — قراءة/كتابة من Cloud مع `localStorage` كـ fallback.
- `student.tsx` — إعادة هيكلة كاملة (إخفاء قائمة الطلاب، إظهار بيانات الطالب بعد إدخال الهوية).
- `teacher.tsx` — منطق التعيين (كل الطلاب افتراضياً) + إخفاء قيمة درجة الحفظ.
- `musammi.tsx` — إظهار قائمة الانتظار.
- `supervisor.tsx` + `admin.tsx` — زر «السماح بإعادة السرد فوراً».
- `admin.tsx` — جدول غياب اليوم + أزرار واتساب.
- `manager.tsx` — تبويب «المستخدمون والصلاحيات».
- `dashboard.tsx` — استيراد Google Sheets يكتب في Cloud.

**جدول قاعدة البيانات:**
```text
students(id, name, halaqa_id, national_id UNIQUE, parent_phone,
         level, level_type, assigned_to, memorized)
halaqat(id, name, is_talqeen, teacher_name, teacher_code,
        assistant_name, assistant_code)
role_accounts(id, role, name, code, permissions text[])
grades(student_id, week, data jsonb)
sard_queue(...)  sard_history(...)
attendance_daily(student_id, date, status)
```

**RLS:** قراءة عامة، الكتابة عبر Server Functions تتحقق من الرمز المُرسل.
