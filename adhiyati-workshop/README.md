# ورشة مشروع أضحيتي 1447

تطبيق ويب تفاعلي لإدارة ورشة تطوير مشروع أضحيتي — جمعية الزاد. يدعم العرض التقديمي، مشاركة الفرق، والتصويت المباشر.

## الميزات

- **الصفحة الرئيسية** — QR للانضمام، روابط المشارك والتصويت
- **لوحة التحكم** — إدارة مراحل الورشة، الشرائح، التصويت، وقفل المحاور
- **العرض التقديمي** — شاشة كبيرة مع شرائح العرض وبانر التحديات الاتجاهية والتقرير الختامي
- **واجهة المشارك** — 7 مراحل: تسجيل، حجز محاور، عصف ذهني، ترتيب، تصويت، تحسينات، تقرير
- **التصويت العام** — تصويت الجمهور على التحديات والتحسينات

## التقنيات

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Supabase (Realtime + PostgreSQL)
- qrcode.react

## البدء

```bash
npm install
cp .env.example .env.local
# أضف مفاتيح Supabase في .env.local
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## إعداد Supabase

1. أنشئ مشروع Supabase جديد
2. نفّذ migration من `supabase/migrations/001_workshop_schema.sql`
3. فعّل Realtime للجداول (مضمن في الـ migration)
4. انسخ URL و anon key إلى `.env.local`
