## ما يتضمنه الإصدار الجزئي

- F13: حصر تقرير الأوجه في تواريخه، وإظهار التعويض الأسبوعي غير المؤرخ منفصلًا.
- F20 جزئيًا: نسبة الخطة والاكتمال يستعملان نطاق البداية نفسه؛ البداية غير الموجودة لا تنتج اكتمالًا. التحقق الخلفي الجديد وتاريخ التعيينات باقيان في #22.
- F21: القيم half/one/two وحدها تُعد حفظًا في الحسابات والتقارير والتصدير المرتبط.
- F22: صفر علمي تقييم مسجل ضمن الفترة وأيام العمل نفسها؛ الفراغ أو قيمة غير رقمية ليس تقييمًا.

لا تتغير الأوزان أو التقريب أو الاجتياز أو سياسة المحاولات. ملفات API ومخطط البيانات والدخول والصلاحيات والملكية وعزل المجمعات لم تتغير. تصريحات التخزين والمزامنة محفوظة كما في الأساس، والاختبار يقارنها حرفيًا بعد استبعاد دوال الحساب المحددة. لا إعادة كتابة لدرجات قديمة عند النشر.

## القبول والنشر والتراجع

اختبارات الحسابات تشمل الفترة الجزئية والتعويض غير المؤرخ، بداية المنتصف والبداية غير الموجودة، المفقود والصفر، وصفر مسجل في يوم خارج الفلتر. اختبارات النطاق تثبت بقاء API والمخطط والتخزين والصلاحيات والاعتماديات كما كانت. يُبنى ويُتحقق من حزمة Hostinger الفعلية قبل الدمج.

التحقق المحلي: نجحت برامج الاختبار السبعة للعميل واختبار النسخ الاحتياطي/الاستخراج المعزول، ونجح build:hostinger بما فيه SSR وتوليد index والتحقق من الحزمة. فحص TypeScript الكامل لم ينجح: 33 تشخيصًا في الإصدار الجزئي مقابل 35 في الأساس، دون تشخيص جديد. لم تختبر رحلة متصفح بحسابات حقيقية.

قبل الرفع تُحفظ نسخة خاصة على الاستضافة خارج public_html لمدخلات الواجهة التي سيجري رفعها، وتُختبر بإعادة استخراج معزولة. تُحفظ الملفات البعيدة الإضافية، وأزيل --delete من بدائل rsync. يقارن مسار النشر تغييرات api/؛ هذا الإصدار لا يرفع API لأنها لم تتغير. لا تختبر حسابات حقيقية أو تكتب درجات للتحقق من النشر؛ التحقق المنشور مقتصر على ملف الإصدار الثابت.

التراجع من هذا الإصدار الجزئي هو إعادة واجهة النسخة السابقة من الأرشيف الخاص أو إصدار مقابل؛ ليس فيه تراجع قاعدة بيانات، لأن المخطط والسجلات لم يتغيرا. لا تُحذف ملفات API أو إعداداتها أو السجلات أثناء التراجع. حدود التراجع المختلفة بعد المخطط الجديد ما زالت موثقة في فرع #22 ولا تنطبق على إصدار الحسابات هذا.
