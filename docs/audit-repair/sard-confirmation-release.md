القبول يشغل القارئ والخطاف الفعليين ببيانات اصطناعية: رد بلا مفتاح مع قائمة محفوظة، إعادة المحاولة، قائمة جديدة فارغة، كتابة أحدث أثناء القراءة، سياق مجمع خاطئ، تبديل جلسة، طلبات متزامنة، بلوغ الموعد والصفحة مفتوحة وتنظيف المؤقتات. تبقى كل اختبارات الواجهة وPHP والمحركات المعزولة السابقة، ومقارنة TypeScript والبناء.

التراجع يعيد واجهة الأساس المنشور مع بقاء API والبيانات. لم يستحدث الإصدار تنسيقًا ولا يعدل مخزنًا عند تحميله؛ اختبرت قراءة الأساس للحالات الحالية وحفظها، مع بقاء الفراغ العلمي الصريح وقواعد المراجعات المثبتة ومنع التصفير من #33/#34. الحزمة مختبرة والبصمة محفوظة، دون استعادة قاعدة أو درجات قديمة. إذا أدخل إصدار لاحق تنسيقًا جديدًا، يعاد تقييم حزمة التراجع على نسخته قبل استخدامها.
