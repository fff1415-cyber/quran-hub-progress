تبقى قاعدة انتهاء التحرير كما هي: الخانة الفارغة قد تعود للدرجة التلقائية وفق التحضير والإعدادات الحالية. تغيير هذه القاعدة ليس ضمن الدفعة. لا تغيير للأوزان أو الاجتياز أو المحاولات أو التقريب أو الإعفاء أو مصدر الإعدادات، ولا API أو مخطط أو أدوار أو دخول أو ملكية أو نطاق وصول.

هذه ليست معالجة كاملة لتعارض جهاز قديم يرفع قيمة مختلفة إلى الخادم؛ بروتوكول الخلايا والتوافق مع الجلسات القديمة يأتيان في دفعة مستقلة. يثبت الاختبار المقصود أن **العميل المصحح** يدمج سحابة أقدم دون عودة الدرجة أثناء التحرير، لا أن كل كاتب قديم أصبح آمنًا.
